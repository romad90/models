# CS229 : Machine Learning

**Enseignant** : Andrew Ng (et d'autres selon les années). Version vidéo de référence : automne 2018.

## C'est quoi ?
C'est le cours fondateur du ML à Stanford, et le plus mathématique du parcours : apprentissage supervisé (régression, classification, SVM), théorie de l'apprentissage (biais/variance), arbres et ensembles, réseaux de neurones, non supervisé (k-means, EM, ACP) et une introduction au renforcement.

> [!examen] Pourquoi pour la mission
> - **Examen** : nourrit [[Domaine 3 Passer du prototype au modèle]] (choix du modèle, régularisation, sur-apprentissage) et les questions de métriques.
> - **Entretiens** : « explique le compromis biais/variance », « pourquoi la régression logistique utilise une sigmoïde », etc. Ces questions reviennent toujours, et CS229 y répond.

## Prérequis
- Algèbre linéaire, probabilités, dérivées : voir [[M1 Fondations Python et maths]].
- Python et NumPy.
- Si les maths te freinent, commence par la *Machine Learning Specialization* sur Coursera, qui couvre les mêmes idées plus doucement.
