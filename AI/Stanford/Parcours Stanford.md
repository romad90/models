# 🎓 Parcours Stanford

> [!examen] Pourquoi Stanford, si l'examen porte sur Google Cloud ?
> L'examen [[Examen PMLE - vue d'ensemble|PMLE]] vérifie que tu sais **choisir et opérer** les bons services. Les entretiens d'embauche, eux, vérifient que tu **comprends** les modèles : biais/variance, rétropropagation, choix d'une métrique, conception d'un système. Les cours de Stanford couvrent ce second besoin. Ils servent la [[MISSION]] (décrocher le poste), pas seulement la certification.

## Gratuit ou payant ?
- **Gratuit** : toutes les vidéos sur la chaîne YouTube *Stanford Online*, et les notes de cours sur les sites des cours. C'est ce que suit ce parcours (mode « auditeur libre »).
- **Payant** : les certificats officiels Stanford Online (inscription SCPD), avec devoirs corrigés. Ils ne sont pas nécessaires pour la mission.
- **Coursera** : l'audit est en général gratuit, le certificat payant (abonnement).

> [!tip] Règle d'or pendant les 6 mois
> Pendant la préparation, **ne regarde pas les cours en entier**. Prends seulement les cours listés dans chaque fiche. Tout le reste attend le parcours « après la certif ». Le hors-périmètre est défini dans la [[MISSION]].

## Après la certification (mois 7–12)
1. **Mois 7–8** : [[CS229]] en entier, avec les *problem sets*, pour réviser les entretiens techniques.
2. **Mois 8–9** : [[CS224N]] en entier, devoirs inclus (PyTorch).
3. **Mois 9–10** : [[CS329S]], relu avec le livre de Chip Huyen. Entraîne-toi aux questions de *ML system design*.
4. **Mois 10–12** : [[CS336]], pour qui vise les postes LLM / IA générative.

### Bonus facultatifs
- **CS25 – Transformers United** : séminaire de conférences invitées sur l'état de l'art des Transformers. Pour la veille, pas pour apprendre. Site : https://web.stanford.edu/class/cs25/ (lien à vérifier)
- **CS234 – Reinforcement Learning** (Emma Brunskill) : seulement si l'apprentissage par renforcement t'attire (RLHF, robotique). Hors périmètre de l'examen. Site : https://web.stanford.edu/class/cs234/ (lien à vérifier)
