## Mots-clés de contrainte à repérer
| Si l'énoncé dit… | …pense à |
|---|---|
| « minimiser l'effort, peu d'expertise ML » | API pré-entraînée, AutoML, BigQuery ML |
| « les données sont déjà dans BigQuery » | BigQuery ML |
| « reproductible, automatisé » | Pipelines, CI/CD |
| « faible latence, temps réel » | endpoint en ligne |
| « gros volume, pas urgent » | prédiction par lots |
| « les performances baissent dans le temps » | Model Monitoring, dérive, ré-entraînement |
