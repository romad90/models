# M4 Google Cloud et Agent Platform

Retour : [[00 Accueil]] · Précédent : [[M3 Deep learning]] · Suivant : [[M5 Données et features]]

> [!examen] Pourquoi
> Le domaine 1 (environ 13 %) porte sur les solutions **low-code** : BigQuery ML, API pré-entraînées, AutoML, Model Garden. La règle de l'examen : prendre **la solution managée la plus simple qui répond au besoin**.

> [!warning] Renommage
> Depuis avril 2026, Vertex AI s'appelle **Gemini Enterprise Agent Platform**. Garde [[Correspondance des noms Vertex AI]] sous la main : beaucoup de tutoriels utilisent encore les anciens noms.

## Compétences visées
- [ ] Créer un budget et une alerte de facturation (avant tout le reste !)
- [ ] Entraîner, évaluer et faire prédire un modèle en SQL avec BigQuery ML
- [ ] Choisir entre API pré-entraînée, AutoML, BigQuery ML et entraînement personnalisé, voir [[Choisir le bon service Google Cloud]]
