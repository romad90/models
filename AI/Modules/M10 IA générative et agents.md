# M10 IA générative et agents

Retour : [[00 Accueil]] · Précédent : [[M9 Monitoring et IA responsable]] · Suivant : [[M11 Révisions et examen]]

> [!examen] Pourquoi
> L'examen de 2026 a été réécrit autour de Gemini Enterprise Agent Platform. L'IA générative traverse plusieurs domaines : choix d'un modèle dans Model Garden, RAG, *fine-tuning*, évaluation et déploiement d'agents. C'est aussi ce que demandent les offres d'emploi.

## Thèmes
- LLM : *tokens*, *prompting*, température, fenêtre de contexte
- **RAG** : embeddings, Vector Search, découpage (*chunking*) et ancrage (*grounding*)
- Adapter un modèle : *prompt engineering*, *fine-tuning* supervisé, réglage efficace (LoRA) ; quand utiliser chaque approche ?
- Agents : outils, Agent Studio, Agent Runtime (ex-Agent Engine), Agent Development Kit (ADK)
- Évaluer un LLM : jeux d'évaluation, *LLM-as-a-judge*, filtres de sécurité

## Compétences visées
- [ ] Construire un mini-RAG sur tes notes Obsidian (embeddings, Vector Search, puis Gemini)
- [ ] Choisir entre *prompting*, RAG et *fine-tuning* dans un scénario
- [ ] Déployer un agent simple et l'évaluer
